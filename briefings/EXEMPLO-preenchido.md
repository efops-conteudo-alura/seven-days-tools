## tema
Construindo uma API que consome dados de personagens de um jogo retrô

## o-que-vai-praticar
Durante os 7 Days de Python, você vai praticar a construção de uma <strong>API back-end</strong> do zero, consumindo dados externos, tratando informações e organizando seu código em boas práticas. É a chance de sair da teoria e colocar a mão na massa em um projeto que você poderá mostrar no seu portfólio.

## dia-1
No primeiro dia você vai preparar o ambiente e criar a estrutura inicial do projeto em Python.

## dia-2
Aqui você fará a primeira <strong>requisição a uma API externa</strong> e vai entender como tratar a resposta.

## dia-3
Nesse dia você vai modelar os dados dos personagens e organizar tudo em funções reutilizáveis.

## dia-4
Você vai criar seus próprios endpoints, começando a montar a sua API.

## dia-5
Hora de adicionar tratamento de erros e deixar a API mais robusta.

## dia-6
Nesse dia você escreve testes automatizados para garantir que tudo funciona.

## dia-7
No último dia você vai publicar sua API na internet e fechar o projeto com chave de ouro.
